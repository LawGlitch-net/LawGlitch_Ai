2. Scope & Separation of Systems

To provide transparency, we distinguish clearly between the data environments of different components:

  • LawGlitch Static Marketing Website: An informational website hosted on Cloudflare Pages. It does not provide user logins, maintains no backend database, and does not record marketing tracking cookies.
  • Alfie Base Browser Extension: Available on Microsoft Edge, with builds in preparation for Google Chrome and Firefox. It operates locally inside the user's browser, parsing tasks and DOM controls on-device without cloud telemetry.
  • Third-Party Websites Visited: Web pages visited by the user maintain their own independent terms, tracking, and privacy policies. Alfie's local execution does not change or alter those websites' independent practices.
  • Browser Stores: Google Chrome Web Store, Microsoft Edge Add-ons, and Mozilla Add-ons collect their own store telemetry, download metrics, and crash data according to their respective policies.

3. Data Practices & Local Execution

3.1 Website Technical Access Logs

When you visit this marketing website, our hosting provider (Cloudflare Pages) processes basic HTTP request headers to serve requested files and protect against automated DDoS attacks:

  • Client IP address and coarse regional location.
  • Timestamp, HTTP method, and requested asset path.
  • Browser user-agent string and referrer URL.

Legal Basis: Legitimate interests (Art. 6(1)(f) GDPR / UK GDPR) for network resilience and DDoS mitigation.

3.2 Local-First Extension Processing (Alfie)

Alfie is built on a strict data minimization foundation:

  • Local Model Planning: The base extension uses an on-device model runtime cached permanently by your browser. Step planning occurs entirely inside your local browser process. Prompts and page contents are never routed to remote AI servers.
  • DOM Inspection: Content scripts inspect the active document’s accessible tree to identify interactive buttons, links, and form fields. Element matching is evaluated locally.
  • Form Protection: Alfie avoids reading password fields, authentication tokens, payment details, or hidden input values.
  • Local Storage: Saved workflows, chat histories, and preferences are stored exclusively in your browser’s extension-scoped local storage (chrome.storage.local).

3.3 Voice and Speech Input

Voice commands are optional. Users can select between:

  • On-Device Speech Transcription: Transcribes speech locally inside Alfie’s extension offscreen document without sending audio over the network.
  • Browser-Native Recognition: Utilizes your browser’s built-in Web Speech API, which may route audio through the browser vendor’s speech servers (e.g. Microsoft or Google) according to your browser settings.

9. Technical Security Measures

LawGlitch implements defense-in-depth security measures:

  • Enforced TLS 1.3 encryption across all website assets.
  • Strict Content Security Policy (CSP) blocking unauthorized external scripts and remote framing.
  • Permissions-Policy disabling camera, microphone, and geolocation across public marketing pages.
  • The Alfie extension sandbox limits tool calls strictly to validated signatures; the model cannot execute arbitrary eval() or write to the host filesystem.
